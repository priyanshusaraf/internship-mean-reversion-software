## Why the predictive object is dead — the decisive (object-class) argument
State T's kill is usually told statistically (CSU below noise floor; Var≡AR(1); selection-on-deviation null
reproduces the morphology; MRScore inverted — a pure RW scored highest). True, but the **deepest, most durable
critique** the initiative surfaced is **identification, not power**:

> A "transition" is **defined by the regime that FOLLOWS** the candidate instant. Its label is only knowable
> ex-post. Any per-bar object that emits "this is/will be a transition" therefore uses **post-t data to define
> its own target** — there is **no causally-definable transition LABEL**. This is an *object-class* error
> inherited by **every** successor (Markov-switching, CUSUM-as-transition, run-length-conditioned VR, threshold
> models). It is robust to costume changes.

Every "causal escape" the seven lenses generated collapses under audit into one of four known leaks: (i) a
future-defined label; (ii) a forward `[t, t+h]` read; (iii) a **rolling/online estimator the project has already
proven manufactures the signal** (doc 19: β-update-noise = 82–97% of variance, fabricated VR≫1 on a true-VR<1
series); (iv) **selection-on-deviation** conditioning (doc 11 Phase 5; doc 16 binding demotion of the
run-length-conditioned VR sign-flip as "producible by selection ALONE").

## The nine deliverables
1. **Critique of State T.** Right economic instinct (a sign change in conditional residual drift
   `b(z,t)=E[Δε|ε,state]`; etiology — flow vs information — as the binding variable; parsimonious hazard
   architecture; pre-registered null), attached to the **wrong observable** (CSU, its worst-estimated quantity)
   and the **wrong object class** (a future-defined label treated as a causal per-bar field).
2. **Does State T survive?** **DEAD as a predictive/per-bar object** (KILLED-IN-FORM, stands); **SUBSUMED as a
   question** — its only leak-free residue is a concurrent, unconditional, surrogate-relative transitory-vs-
   permanent characterization, already owned by the WHETHER line (MR Habitat / Arm A). It does **not** survive as
   a distinct deployable transition object, and **cannot be revived by relabeling.**
3. **Better architecture.** Observational-only, **additive** to the habitat owner: a *regime-characterization
   observatory* = a **conditional cut of the existing Habitat object**, not a new module. Characterize, don't
   predict; annotate defensively; measure repeatability before believing anything. Zero new estimator, zero μ*
   dependency, zero per-bar object.
4. **Transition model proposal.** **Honest verdict: a deployable predictive transition cannot be modeled without
   hindsight on the current cohort, and is forbidden as resurrection.** The admissible reformulation is *not*
   "when will it transition" but the time-symmetric, corpus-level **distributional** statement: "post-causal-break
   episodes show surrogate-relative VR(q) below the matched-surrogate curve at a pre-registered horizon more often
   than pre-break episodes," cross-habitat replicated, full-search disclosed. If even that cannot beat its
   surrogate, terminal verdict = transition is not a deployable object ("stopping is a success").
5. **Residual-analysis verdict.** Residual-**SHAPE** analysis (κ, OU-fit λ, residual ACF/half-life, residual-
   variance-compression) is **DEAD as a transition input** (noise-floor / Var≡AR(1) / σ_η-is-volatility /
   smoother-manufactured — empirically proven by MRScore inversion). Residual-**ECOLOGY description** survives
   **narrowly, in return-difference space** (VR(q) real−GARCH-surrogate; a devolatilized-variance hygiene
   contrast), corpus-level, never per-bar, gated — **expected to return a null, which is acceptable.**
6. **Mathematical formulation.** μ*-independent level-difference returns `r_t`. **Primary:**
   `VR(q)=Var(P_t−P_{t−q})/(q·Var(r_t))`, `q∈{2,5,10,20}`, **unconditional**, reported as the full vector (never
   min/argmax-collapsed). Object = `Δ(q)=VR_real(q)−E[VR_surr(q)]`, surrogate run through **bit-identical**
   extraction (artifact + doc-19 rolling artifact cancel). Test `T_q=Δ(q)/ŝ_q` from the surrogate ensemble (raw VR
   inadmissible — Lo–MacKinlay small-sample bias). Hygiene: recompute on devolatilized `r_t/σ̂_t` — attenuation ⇒
   GARCH not transition. **Evidence unit = persistence across M≥3 disjoint windows × ≥2 habitats**, multiplicity-
   deflated. **Defensive annotator (separate, never in the verdict):** recursive innovation-CUSUM break flag on
   the frozen Kalman-μ* innovation, with a synthetic-calibrated detection-lag distribution. Honest prior on
   "survives everything": **LOW.**
7. **Trader interpretation.** A 1–12-week PM would **not** fund a transition signal, correctly: (i) **wrong
   bottleneck** — cost/capacity/netting, not timing (NG precedent: real MR, break-even before cost; a perfect
   timer funds nothing); (ii) **catastrophic-asymmetric false positive** — a wrong "transition now" fades a
   continuing trend, the σ-stop fires at max divergence, unbounded tail if the move was permanent repricing;
   (iii) **detection lag + unobservable mechanism** — confirms after the reversion is half over; the driver
   (signed flow) is unobserved on spreads. What a desk *would* fund: the VR(q) characterization as a **no-trade-
   environment / selectivity input**, a **defensive-only CUSUM** cut-flag, and a cross-asset stress **stand-aside**
   gate — risk overlays on a book that already clears costs as a portfolio.
8. **Smallest implementable version.** A **characterization-only** add to the Habitat object, zero predictive
   surface. Pre-register first (q-grid; surrogate family + calibration; M≥3 disjoint windows; ≥2 habitats; full
   cohort; devolatilization recipe; **kill criterion = real≈surrogate ⇒ clean NULL, close the arm**). μ*-
   independent (no §15.8 trip; μ* only a descriptive replay line). May claim a retrospective regime description;
   **may not** emit any per-bar/forward/thresholdable/"favorable-now" scalar (the MRScore-inversion firewall:
   reject any value an `ORDER BY`/`>` can consume). **Gated** behind an §11.8 positive control *for this object*
   + a verified-MR habitat; evaluated at the **book level after costs.** Expected outcome: a null = success.
9. **Coding roadmap.** Step 0 pre-registration doc (load-bearing) → Step 1 **positive control for this object**
   (apparatus must detect a known reverter under the identical ecology pipeline; else recalibrate the apparatus)
   → Step 2 surrogate engine + **bit-identical extraction** parity (unit-test on synthetic true-VR<1) → Step 3
   unconditional VR(q) Δ(q) with CIs, full cohort → Step 4 devolatilization hygiene gate → Step 5 repeatability
   (M≥3 windows × ≥2 habitats, multiplicity-deflated, full search) → Step 6 defensive CUSUM annotator (replay-only,
   never entry) → Step 7 **book-level cost evaluation** (the real question). **Do NOT build:** any per-bar
   transition score, rolling-OLS-β / rolling-κ / rolling-Hurst / rolling-OU-fit, residual-shape feature,
   full-sample change-point label, forward `[t,t+h]` read wired to a signal, HMM/SETAR transition matrix. If
   Step 1 or Step 3/5 returns real≈surrogate, **STOP and record the null.**
